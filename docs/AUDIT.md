## 4. Known Verification Limitations

1. **Physical Microphone Hardware:**  
   In automated testing and headless Chromium environments, acoustic capture through a physical hardware microphone could not be exercised. All Web Speech API event sequences (`onstart`, `onresult` with interim/final flags, `onerror`, `onend`, `abort`, `stop`) were rigorously verified using mock implementations in Vitest and interactive browser DOM testing.
2. **Physical Audio Speaker Output:**  
   Acoustic speaker output from `speechSynthesis.speak()` was verified via DOM dispatch and speech synthesis event binding rather than physical audio decibel measurement.
3. **External ONNX Model Weights:**  
   The project is preconfigured in `MODEL_MODE=demo` so judges and evaluators can immediately run the entire system locally without requiring pre-trained multi-gigabyte ONNX weights or external cloud API keys. Real ONNX model loading is supported when weights are placed at `MODEL_PATH`.
